# github_actions_web_hosting

## Project URL

https://roadmap.sh/projects/github-actions-deployment-workflow

This repository demonstrates how to deploy a simple static website to **GitHub Pages**
using **GitHub Actions**.

## 📦 What this project does

- Hosts a simple `index.html` page
- Uses a GitHub Actions workflow to deploy the site to GitHub Pages
- Automatically redeploys **every time `index.html` changes on the `main` branch**

## 🚀 Deployment

The site is deployed using GitHub Actions and is available at:

https://piratekingDevOps.github.io/github_actions_web_hosting/

## 🔁 How it works

1. A push is made to the `main` branch
2. If `index.html` changes, the workflow runs
3. GitHub Pages is updated automatically

## 🛠 Technologies used

- HTML
- GitHub Actions
- GitHub Pages
